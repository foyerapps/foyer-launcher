# Foyer Launcher

Tous tes jeux PC dans une seule app : bibliothèque, Découvrir, Soirée, Magasin et comparateur de prix, promotions.

## Installer

Télécharge `FoyerLauncher-Setup.exe` dans [Releases](https://github.com/foyerapps/foyer-launcher/releases/latest), puis double-clique. Windows 10/11, 64 bits.

L'app n'est pas signée : Windows peut afficher « Windows a protégé votre ordinateur » → *Informations complémentaires* → *Exécuter quand même*. Le fichier `FoyerLauncher-Setup.exe.sha256` permet de vérifier le téléchargement. L'app se met à jour toute seule.
